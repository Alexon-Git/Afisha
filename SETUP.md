## 🚀 Быстрый запуск

### Вариант 1: Запуск всего проекта одной командой
```bash
python start_all.py
```

### Вариант 2: Пошаговый запуск

#### 1. Запуск бэкенда
```bash
cd backend
python start.py
```

Этот скрипт:
- Создаст .env файл из env.example (если его нет)
- Установит зависимости
- Создаст базу данных
- Создаст администратора из ENV файла
- Заполнит тестовыми данными
- Запустит сервер на http://localhost:8039

#### 2. Запуск фронтенда
```bash
cd frontend
npm install
npm start
```

Фронтенд будет доступен на http://localhost:3000

### 🔧 Настройка администратора

Создайте файл `.env` в папке `backend/` или отредактируйте существующий:

```env
# Данные администратора
ADMIN_USERNAME=your_admin_username
ADMIN_PASSWORD=your_secure_password
ADMIN_EMAIL=admin@yourdomain.com
```

Администратор будет создан автоматически при первом запуске.

## 🔧 API Endpoints

- `GET /events` - список мероприятий с фильтрацией
- `GET /events/{id}` - детали мероприятия
- `POST /events` - создание мероприятия (требует авторизации)
- `PUT /events/{id}` - обновление мероприятия
- `DELETE /events/{id}` - удаление мероприятия
- `POST /events/upload-image` - загрузка изображения
