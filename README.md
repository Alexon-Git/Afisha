# Афиша мероприятий

Современный веб-сервис для организации и просмотра мероприятий с красивым дизайном и удобным интерфейсом.

## 🚀 Особенности

- **Современный дизайн** - Использует TailwindCSS для создания красивого и адаптивного интерфейса
- **Календарь мероприятий** - Интерактивный календарь с подсветкой дат с событиями
- **Админ-панель** - Полноценная система управления мероприятиями
- **Загрузка изображений** - Возможность загружать афиши мероприятий
- **Аутентификация** - Безопасная система входа с JWT токенами
- **API документация** - Автоматически генерируемая документация FastAPI

## 🛠 Технологический стек

### Backend
- **FastAPI** - Современный веб-фреймворк для Python
- **SQLAlchemy** - ORM для работы с базой данных
- **PostgreSQL** - Основная база данных (SQLite для разработки)
- **JWT** - Аутентификация и авторизация
- **Alembic** - Миграции базы данных

### Frontend
- **React 18** - Библиотека для создания пользовательских интерфейсов
- **TypeScript** - Типизированный JavaScript
- **TailwindCSS** - Utility-first CSS фреймворк
- **React Router** - Маршрутизация
- **React Hook Form** - Управление формами
- **Axios** - HTTP клиент
- **React Calendar** - Компонент календаря

### DevOps
- **Docker** - Контейнеризация
- **Docker Compose** - Оркестрация контейнеров

## 🚀 Быстрый старт

### Вариант 1: Запуск с Docker (Рекомендуется)

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd afisha
   ```

2. **Запустите все сервисы:**
   ```bash
   docker-compose up --build
   ```

3. **Откройте приложение:**
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8000
   - API документация: http://localhost:8000/docs

### Вариант 2: Локальная разработка

#### Backend

1. **Перейдите в директорию backend:**
   ```bash
   cd backend
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте администратора:**
   ```bash
   python create_admin.py
   ```

5. **Запустите сервер:**
   ```bash
   uvicorn app.main:app --reload
   ```

#### Frontend

1. **Перейдите в директорию frontend:**
   ```bash
   cd frontend
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите приложение:**
   ```bash
   npm start
   ```

- **Управление мероприятиями** - CRUD операции

## 🗄 База данных

### Модели

#### User (Пользователи)
- `id` - Уникальный идентификатор
- `username` - Имя пользователя
- `password_hash` - Хеш пароля
- `is_admin` - Флаг администратора

#### Event (Мероприятия)
- `id` - Уникальный идентификатор
- `title` - Название мероприятия
- `description` - Описание
- `datetime` - Дата и время проведения
- `location` - Место проведения
- `image_url` - URL изображения (афиши)
- `creator_id` - ID создателя (связь с User)

## 🔧 API Endpoints

### Аутентификация
- `POST /auth/login` - Вход в систему
- `GET /auth/me` - Получение информации о текущем пользователе

### Мероприятия
- `GET /events/` - Список всех мероприятий
- `GET /events/{id}` - Детали мероприятия
- `POST /events/` - Создание мероприятия (только админ)
- `PUT /events/{id}` - Обновление мероприятия (только админ)
- `DELETE /events/{id}` - Удаление мероприятия (только админ)
- `POST /events/upload-image` - Загрузка изображения (только админ)
