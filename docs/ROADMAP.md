## Принятая стратегия (кратко)

- Публичный сайт с первого релиза, без обязательного закрытого пилота (D-014). Каталог без авторизации, постоянные адреса событий, индексируемый HTML, метаданные, Open Graph, `sitemap.xml`.
- Публичная часть — Next.js (self-hosting: standalone, Docker, Nginx), админка остаётся на React SPA, FastAPI — единый backend. Один origin.
- Время хранится в UTC, вводится и показывается в Asia/Novosibirsk.
- Каталог наполняет вручную сотрудник (5–10 ч/нед) из открытых источников; у каждого события есть первоисточник и дата проверки (D-015, D-016).
- Монетизация ручная, B2B; параллельно разработке (D-018). Реклама, CRM и прогноз посещаемости отложены (D-013).
- После запуска — 8 недель оценки спроса без автоматических порогов закрытия (D-017).

## Гейты качества

**Перед PR:** описание и приёмка, тесты, секреты и чужие БД не затрагиваются, ломающие изменения указаны, коммит только поимённо добавленных файлов; документацию аудита не смешивать с кодом.
**Перед merge:** CI зелёный, затронутый frontend собирается, ревью, обновлён `DEVELOPMENT_CONTEXT.md`.
**Перед продакшеном:** миграции на копии, восстановление из бэкапа проверено, smoke-тест, мониторинг, назначен ответственный.
