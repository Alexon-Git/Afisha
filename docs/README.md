# Документация проекта Afisha

Этот каталог — долговременная память проекта для людей и AI-агентов.
Обновляйте его при существенных изменениях.

| Файл | Назначение |
| --- | --- |
| [PROJECT_PASSPORT.md](PROJECT_PASSPORT.md) | Цель проекта, аудитории, scope, гипотезы, риски, критерии успеха |
| [PRODUCT_REQUIREMENTS.md](PRODUCT_REQUIREMENTS.md) | Функции MVP (P0/P1/P2), данные, сценарии и критерии приёмки |
| [ROADMAP.md](ROADMAP.md) | Очерёдность работ, статус, зависимости, release gates |
| [DEVELOPMENT_CONTEXT.md](DEVELOPMENT_CONTEXT.md) | Что реально есть в коде и что изменилось, проблемы и тесты |
| [DECISIONS.md](DECISIONS.md) | Журнал принятых, предложенных и открытых решений |
| [AGENT_HANDOFF.md](AGENT_HANDOFF.md) | Краткое состояние и задача следующему агенту |

В корне репозитория:
- [AGENTS.md](../AGENTS.md) — общие инструкции для агентов.
- [CLAUDE.md](../CLAUDE.md) — инструкция для Claude Code.
- [README.md](../README.md) — установка/запуск проекта.

Техническая инструкция безопасного развития БД:
[backend/MIGRATIONS.md](../backend/MIGRATIONS.md).

**Важный принцип:** в документах не хранить секреты, реальные
дампы баз или незащищённые персональные данные. Не смешивать
планы и фактически выполненные изменения.

Для запуска Codex в локальной папке проекта: [CODEX_SETUP.md](CODEX_SETUP.md).
