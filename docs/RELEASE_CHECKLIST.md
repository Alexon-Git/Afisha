# Release checklist — публичный запуск «Бизнес Афиши»

**Дата:** 2026-11-12. **Статус:** все пункты не выполнены, если не отмечено иное.
Чекбокс ставится только после проверки с доказательством (команда, ссылка на CI, скриншот). Задачи T1–T19: `TECHNICAL_PLAN.md`. Не всё здесь — P0, но запуск без каждого пункта запрещён, пока владелец не зафиксировал исключение.

## 1. Безопасность авторизации и API
- [ ] Rate limiting `/auth/login` в `master`, тесты лимита, сброса, конкурентности, недоступного хранилища (T1)
- [ ] Миграция `0002_login_attempts` применена на PostgreSQL (чистая БД и копия старой схемы)
- [ ] Uvicorn запускается без доверия произвольным proxy headers; доверие только адресу реального Nginx
- [ ] `python-multipart` обновлён, версия зафиксирована после прогона тестов; размер HTTP body ограничен на Nginx (T2)
- [ ] Все write-маршруты отклоняют анонимов, неверный и просроченный токен, пользователя без `is_admin` (T16)
- [ ] `.dockerignore` исключает `.env`, `.venv`, `node_modules`; секретов нет в образах и репозитории (T15)
- [ ] Backend и PostgreSQL недоступны из внешней сети

## 2. Данные и публикация
- [ ] Миграции применяются на PostgreSQL: пустая БД и копия старой схемы; откат проверен
- [ ] FK включены и проверены на PostgreSQL (SQLite не доказывает паритет)
- [ ] Organizer, `event_url`, `source`, `verified_at`, статусы добавлены без поломки существующих записей
- [ ] Публикация проходит проверку обязательных полей D-019 на backend; то же при правке опубликованного события
- [ ] `verified_at` ставится только явным действием редактора
- [ ] Черновики недоступны публично и отсутствуют в sitemap
- [ ] Опубликованные отменённые и перенесённые события доступны с заметным уведомлением
- [ ] Описания и URL проходят безопасный рендеринг (нет сырого HTML, только http/https)

## 3. Время и диапазоны дат
- [ ] Семантика старых datetime установлена по фактическим данным, миграция не сдвинула время (§2 плана)
- [ ] Хранение в UTC (`timestamptz`), API отдаёт ISO 8601 с зоной
- [ ] Диапазон `[начало первого дня, начало дня после последнего)` в Asia/Novosibirsk; тесты границ
- [ ] Админка: round-trip времени одинаков под `TZ` = Asia/Novosibirsk, UTC, America/Los_Angeles, Europe/Moscow
- [ ] «Сегодня/выходные» считаются по Asia/Novosibirsk, не по времени сервера

## 4. Публичный сайт и SEO
- [ ] Production build Next.js (standalone) успешен
- [ ] Страницы `/`, каталог, `/events/{id|slug}`; 404 для несуществующих
- [ ] Проверка HTML без выполнения JavaScript (`curl`): основной контент и метаданные в ответе
- [ ] Контент для пользователей и роботов одинаков
- [ ] title, description, canonical, Open Graph на каждой странице события
- [ ] schema.org Event только при достоверных данных; `eventStatus` для отмены и переноса
- [ ] `sitemap.xml` и `robots.txt`; в sitemap только опубликованные
- [ ] Кеш и обновление: изменение, отмена и скрытие события видны на сайте за согласованное время
- [ ] Мобильный просмотр и основные сценарии «найти → открыть → перейти на регистрацию»

## 5. Маршрутизация и сборка
- [ ] Nginx: `/` → Next.js, `/admin` → CRA, `/api/` → FastAPI, uploads отдаются
- [ ] CRA собран с `PUBLIC_URL=/admin`; ресурсы админки не конфликтуют с `/static/uploads/`
- [ ] Next.js достучался до backend по внутреннему URL в Docker-сети; браузерный URL — `/api`
- [ ] Production build React-админки успешен
- [ ] CI собирает все приложения и прогоняет тесты
- [ ] Production-домен утверждён владельцем и подставлен в конфиги и CORS (старый `afisha.lalexonl.ru` пересмотрен)

## 6. Эксплуатация
- [ ] SSL, редирект HTTP → HTTPS
- [ ] Бэкап PostgreSQL по расписанию **и восстановление проверено**
- [ ] Бэкап загруженных файлов и восстановление проверено
- [ ] Мониторинг доступности и ошибок 5xx, оповещение ответственному
- [ ] Процедура отката: предыдущие образы, откат миграций или восстановление из бэкапа, кто принимает решение
- [ ] Права на файловые тома и том uploads проверены на сервере

## 7. Аналитика (D-017)
- [ ] Решение по аналитике принято и ресурсы сервера проверены
- [ ] Собираются: уникальные и возвращающиеся посетители, просмотры каталога и карточек, переходы к регистрации, источники трафика
- [ ] Приватность проверена для конкретной конфигурации (IP, cookies, хранение); соответствие требованиям не заявляется без проверки

- [ ] Начаты коммерческие переговоры (D-018); обещаний неподтверждённых охватов нет
- [ ] Правила использования чужих текстов и изображений соблюдены (D-016)
