# Afisha: P0-аудит с ограниченным контекстом

1. Сначала прочитай `AGENTS.md` и `docs/AGENT_HANDOFF.md`.
2. Проверяй только необходимые файлы, в первую очередь `backend/app/auth/auth.py`, `backend/app/routers/auth.py`, `backend/app/services/event_service.py`, `backend/app/main.py`, `backend/app/config.py`, `backend/MIGRATIONS.md`.
3. Не запускай дополнительные модели, gstack, Docker, браузер или сетевые действия. Если пользователь отдельно разрешил конкретный gstack-скилл, это ограничение можно пересмотреть только в пределах разрешения.
4. Дай максимум 5 проверяемых проблем уровня P0/P1 с путём, строкой, сценарием и минимальным исправлением; не выдавай предположения за доказанные ошибки.
5. Не изменяй код без явного запроса. Отчёт краткий и воспроизводимый. При отдельном запросе сохрани в `docs/audits/`.
