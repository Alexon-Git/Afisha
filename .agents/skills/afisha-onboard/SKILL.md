# Afisha: быстрый онбординг

1. Прочитай корневой `AGENTS.md`. Он задаёт приоритетные правила.
2. Прочитай `docs/AGENT_HANDOFF.md`; при необходимости открой соответствующие разделы `docs/ROADMAP.md`, `docs/PROJECT_PASSPORT.md`, `docs/DEVELOPMENT_CONTEXT.md`.
3. Запусти **только локальные чтения**: `git status --short`, `git branch --show-current`, `git log -1 --oneline` и `bash scripts/codex-preflight.sh`.
4. Не читай весь репозиторий, не вызывай дополнительные модели, gstack или браузер, пока пользователь не поставил конкретную задачу.
5. Ответь кратко: текущая ветка, незакоммиченные изменения, что уже сделано, следующая задача P0/P1 и блокеры.
6. Не правь файлы и не создавай коммиты без явного запроса.
